# Grid morph destination draft

The reported Details-to-Large-icons detour was observed in Libraries. Source investigation found a deterministic geometry defect, independently of namespace mapping: LayoutRowVisual already interpolated the full-width outgoing list cell toward its narrow grid cell. LayoutItem centered the destination icon inside that intermediate cell, then interpolated the captured icon toward that moving destination again. A wide list therefore pulled the icon right before it returned left. The reverse direction used the list's leading icon position, which does not depend on the interpolated cell width, explaining the directional difference.

RowVisual now carries the un-interpolated destination cell bounds for shaped morphs. LayoutItem computes icon/name destination geometry from those bounds, then performs the component interpolation once. The shared calculation covers both directions, grid-mode changes and retargeted shapes. Destination metrics, scroll and column/header animation retain their existing live behavior; this is not a frozen full-view bitmap snapshot.

Libraries identity was also reviewed. In-place ApplyViewLayout retains the same item vector and indices and its geometry update does not enumerate the Shell. Namespace enumeration already uses canonical CompareIDs matching to retain previous identity keys when delegate PIDL bytes change; worker snapshot matching then maps those retained keys to new indices. No evidence was found to justify changing that identity policy for this report. Concurrent namespace updates could still interrupt a morph: item snapshots previously retained row bounds without its current icon/name rectangles. Capture and commit now retain those rectangles, using the existing identity check before recapturing. Such diffs use the shared shaped reflow path. Removed indices are excluded from destination rows and retained as ghosts.

x64 and ARM64 syntax checks passed with the existing unused PageLength warning. No regressions, production build or publication were performed. Live Explorer reproduction remains unverified. Manual review should include Libraries and ordinary folders, both directions, wide/narrow viewports, non-leading grid columns, rapid reversals, scrolling, horizontal Details scrolling, grouped headings, DPI/RTL and a folder refresh during the morph. If a distinct Libraries mismatch persists, item-identity and icon-rectangle traces are needed to distinguish it from geometry.
