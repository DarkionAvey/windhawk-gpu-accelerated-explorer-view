# Live option and tooltip regression checks

The six live option sweeps expected every settings save to reset the tab's zoom. Theme-only changes and saves with unchanged settings now preserve it. The checks account for both paths, calculate expected font and row sizes independently, and verify that preserved zoom precision and an open rename editor survive those updates. Ordinary option changes still have to restore configured metrics.

The item tooltip check expected the render target's default text antialiasing mode. Opaque tooltip backgrounds now allow explicit ClearType. The check derives its expectation from the mod's selected text policy and the Windows font smoothing settings, while retaining its rendering-parameter checks.

No production code changed for these fixes.
