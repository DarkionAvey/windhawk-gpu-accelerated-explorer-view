# 1.0.7 regression validation

Eight process-isolated, parallel regressions cover this draft's fixes:

- `view-events-roundtrip` and `view-events-this-pc-roundtrip`: real ExplorerBrowser navigation and Shell view-mode notifications, with the HWND input observer deliberately disconnected. Check returning from another folder, renewed folder generations, mode adoption and focus preservation. Filesystem fixtures are private; This PC is an intentional read-only known-folder probe.
- `view-morph-96` and `view-morph-144`: both directions between Details, icons, Tiles and Content, including RTL, component endpoints and interrupted transitions. Icon and filename rectangles follow independently calculated paths between settled endpoints.
- `view-morph-directory-diff`: delete a private file during a frozen transition, receive the real directory-worker result, and verify surviving identities retain their captured geometry.
- `touch-zoom-fractional-96` and `touch-zoom-fractional-144`: fractional Content/Tiles geometry, wheel interpolation, touch takeover and trackpad policy, including RTL and drive tiles.
- `sticky-group-collapse-anchor`: collapse a partially scrolled sticky heading and retain that heading as the scroll anchor, with the next group expanded or collapsed.

Existing regressions also exposed an unsupported-browser fallback that repeatedly retried subscription setup. An explicit missing IWebBrowser2 interface now settles immediately; temporary failures and unready documents remain eligible for rebinding.

The older Tiles pitch expectation now checks fractional font/DPI arithmetic. Settled grid, namespace-selection and touch fixtures initialize applied layout separately from observed Shell state. The older rapid-zoom continuity check uses the existing held animation clock so its exact geometry assertion compares the same instant.

The first full runs stopped on graphics fixture assumptions and a checkbox insertion expectation. The checkbox completion fence now additionally checks native membership/selection and drained command/import state before the next filesystem mutation. That fence alone did not fix the failure. Selection tracing then showed DefView extending its own Select All selection from five to six items before the GPU import, with no mod selection write-back. The unchecked-insertion case now first deselects an existing item through real checkbox input, then requires that exact four-item native/GPU selection to survive insertion and the new item to remain unchecked. Separate header Select All checks remain. Failure logs retain captured selection decisions. A diagnostic parallel run passed all 157 release C++ entries; it did not publish or replace the failed build receipts. No numeric tolerance or timeout was increased.

These are geometry/component and native COM integration checks. They do not measure displayed Explorer frame rate or replace live touchscreen visual validation.
