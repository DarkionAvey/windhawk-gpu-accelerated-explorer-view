# Scrollbar theme checks

`theme-scrollbar-thumb` and `theme-scrollbar-track` each run in their own process. They draw the production scrollbar into a private GPU target and inspect the returned pixels. No user files, desktop input, focus or clipboard are used.

Both checks cover vertical and horizontal bars at 96, 144 and 192 DPI, in LTR and RTL. They verify normal, hover and pressed colors in light and dark appearance; shared/state inheritance; merged definitions; invalid override fallback; and isolation between thumb and track. Highlight opacity settings are zero during these checks, so an accidental dependency on those settings fails visibly.

Pixel checks cover whole-pixel inside borders, transparent border-only surfaces, solid color alpha, oversized corner-radius clamping, and dithered gradients against independent interpolation. The gradient error bound accounts for nearest-texel sampling and 8-bit color quantization. Warm rendering must be identical without rereading settings. Texture storage is bounded, appearance changes invalidate stale gradients, solid styles retain no dither textures, and device teardown releases gradient resources. Clearing the theme and enabling high contrast must reproduce the full native scrollbar image.

These are offscreen component checks, not live Explorer input or presentation measurements. The existing scrollbar input checks remain separate.

The first run exposed an incorrect test fixture: it overwrote a base radius with invalid text while expecting state inheritance. The corrected fixture places invalid text on the hover override, leaving the base radius available to inherit. The failed run is retained in `tests/.build/theme-scrollbar-20261113-01`.

The next run exposed a second expectation error: horizontal RTL samples are in logical coordinates, but CSS gradient directions are physical. The interpolation expectation now reverses the sampling coordinate for that case, without changing its error bound. That failed run is retained in `tests/.build/theme-scrollbar-20261113-02`. No production changes were needed.
